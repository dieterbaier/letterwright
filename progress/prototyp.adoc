= Prototyp: Vorlagenformat und Rendering absichern

Wegwerf-Prototyp, der ADR-003 bis ADR-005, ADR-014 und ADR-017 an realen
DOCX-Vorgaben belegt oder widerlegt (Epic #3).

*Status:* aktiv seit 2026-11-19. Der Spike ist gebaut (PR #45 und #47 gemergt).
Jetzt warten vier Entscheidungen beim Owner, danach gehen die Ergebnisse in die
ADRs. Die Liste steht im Kommentar zu #3 vom 2026-11-20.

== The plan

Erst die Entscheidungen des Owners, weil von ihnen abhängt, was in ADR-004,
ADR-005 und QS-002 steht. Chromium kommt nur, wenn der Owner die beobachteten
Abweichungen von Option 1 nicht hinnimmt.

(Owner, 2026-11-15).

== Where we are

Der Prototyp liegt in `prototyp/`, außerhalb des Gradle- und npm-Builds. Sein
README beginnt mit einer Tabelle „Funktionen und Grenzen“, je Funktion mit
Nachweis und ADR. Messwerte stehen dort und kommen aus den Befehlen unten, nicht
aus dieser Datei. Bekannte Abweichungen: VoiceOver braucht am Seitenwechsel einen
neuen Einstieg in den Frame, bei 200 % Zoom scrollt die Vorschau statt
umzubrechen, die Fußzeile im PDF wird nur per PDFBox-Nachbearbeitung lesbar und
widerspricht damit dem Antwortmaß von QS-002, QS-004 ist nur am Chrome-Druck-PDF
gemessen.

== Checks

Im Ordner `prototyp/`, Ersatzschriften vorher mit `sh ersatzschriften/laden.sh`:

[source,sh]
----
../gradlew run --args="geschaeftsbrief-mehrseitig"          # PDF, Vorschau, Fußzeilen-Nachweis
../gradlew vergleich --args="referenz/geschaeftsbrief-mehrseitig-word.pdf ausgabe/geschaeftsbrief-mehrseitig.pdf"
npm run pruefen -- geschaeftsbrief-mehrseitig               # Sandbox, CSP, Druck-PDF der Vorschau
../gradlew vergleich --args="ausgabe/geschaeftsbrief-mehrseitig.pdf ausgabe/geschaeftsbrief-mehrseitig-vorschau.pdf"
../gradlew gegenprobe --args="ausgabe/geschaeftsbrief-mehrseitig.pdf"
../gradlew konformitaet --args="ausgabe/geschaeftsbrief-mehrseitig.pdf"
npm run barrierefreiheit -- geschaeftsbrief-mehrseitig
../gradlew run --args="boesartig" && npm run angriff -- boesartig
----
