== Gelernt

* **openhtmltopdf schreibt laufende Elemente immer als Artefakt.** Keine
  Einstellung ändert das. Absolut positionierter Inhalt unterhalb des
  Inhaltsbereichs wandert auf die nächste Seite.
* **Paged.js wendet `@media print` auch auf dem Bildschirm an.** Eine Druckregel
  zum Verbergen trifft deshalb auch die Vorschau.
* **CSP und Bereinigung leisten Verschiedenes.** Die CSP blockiert Code, aber
  nicht `meta refresh`; das verhindert nur die Bereinigung.
* **Ein Vergleich, der nur Abweichungen misst, übersieht Überzähliges.** Erst
  Seitenzahl und Zeilen in beiden Richtungen plus Gegenprobe machten ihn
  belastbar, und er fand sofort einen eigenen Fehler.
* **Ein Nachbearbeitungsschritt braucht einen Nachweis seines Ergebnisses**, nicht
  nur „hat etwas gefunden“ (Review von PR #47).
* **PDFBox 3 schreibt Ligaturen als Unicode-Ligatur in den Text.** Mit PT Sans
  Narrow wird „fi“ zu U+FB01; Suche und Kopieren sind je nach Viewer betroffen.
* **Prüfskripte dürfen nicht ins Netz.** Ein Testlauf klickte einen echten Link
  an eine geparkte Domain. Seitdem bricht das Skript jede Anfrage nach außen ab.
* **Ein Statuswort im README ist eine Behauptung.** „Nicht nötig“ nahm eine
  Entscheidung des Owners vorweg (Review von PR #47).
