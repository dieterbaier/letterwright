== Gelernt

* **Die Schriftentabelle einer DOCX sagt nicht, welche Schriften wirken.** Erst
  die Auflösung über Formatvorlagen, Vererbung und direkte Formatierung zeigt
  es. Eine Schrift kann nur an der Absatzmarke eines leeren Absatzes hängen.
* **„Gleiche Laufweiten“ ist kein Pauschalversprechen.** Für Arial Narrow gibt es
  keine metrisch gleiche OFL-Schrift. Zusammenfassung und Relationen müssen die
  Ausnahme nennen (Review von PR #40).
* **Ein Erfolg mit Ersatzschriften belegt nichts für die Originalschriften.**
  Beide Wege brauchen eigene Nachweise (Review von PR #40).
* **zsh:** Branch-Sweep blockiert wieder wegen Wortaufteilung, unter bash
  `SWEEP: CLEAR`. Zusätzlich verhindert `noclobber` das Überschreiben von Dateien
  mit `>`. Ein Skript arbeitete deshalb einmal mit einer veralteten lokalen Datei
  weiter. Das Ergebnis war zufällig richtig.
