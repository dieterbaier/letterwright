= Vision and Mission
:id: DOC-002-vision-mission

== Vision

Every application can create standard-conformant, accessible and archivable
letters whose design business users decide themselves.

== Mission

letterwright provides an embeddable library. It manages letterheads and
letter templates as maintainable templates, fills them with the host's domain
data, shows an accessible preview and saves immutable PDF/A documents.
