= Value Proposition Canvas
:id: CANVAS-002-value-proposition

Draft, created with AI assistance, not reviewed.

* *Jobs*: create, check, file and send letters; keep templates up to date.
* *Pains*: filling Word templates by hand; layout errors; PDFs that are not accessible; a developer for every text change.
* *Gains*: one click to a preview with real data; business users maintain templates themselves; PDF/A automatically.
* *Pain Reliever*: placeholders from domain data; DIN 5008 building blocks; conformance check.
* *Gain Creator*: versioned templates; fidelity preview = PDF.
