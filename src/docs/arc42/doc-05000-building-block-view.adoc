| Baustein | Verantwortung | Ablage im Repository

| adapter-web | REST-Endpunkte, Fehlerabbildung | `backend/adapter-web`
| adapter-rendering | Zusammenführen (FreeMarker), PDF (openhtmltopdf), Konformität (veraPDF) | `backend/adapter-rendering`
| adapter-persistenz-jdbc | Repositories, DokumentAblage, Liquibase-Changelog | `backend/adapter-persistenz-jdbc`
| spring-boot-starter | Autokonfiguration, Default-Adapter | `backend/spring-boot-starter`
| Frontend-Paket | Vorschau, Übersicht, Editor | `frontend/`
|===
