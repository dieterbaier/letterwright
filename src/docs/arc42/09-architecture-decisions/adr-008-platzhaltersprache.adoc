== ADR-008: Placeholder language with Apache FreeMarker

=== Status

Proposed.

This ADR was created with AI assistance. It counts as an architecture decision
only once the responsible owner has reviewed and accepted it.

=== Decision

We propose **Apache FreeMarker** (Apache-2.0) as the evaluation language:

* Syntax `${recipient.name}`, as the owner had in mind; default values
  `${recipient.salutation!"Dear Sir or Madam"}`; loops `<#list>`;
  conditions `<#if>`.
* Business users do not write this syntax by hand: the editor (ADR-003) inserts
  placeholders, repetition blocks and condition blocks as building blocks.
* **Missing values** without a default are shown visibly as placeholders in the
  preview and the PDF (e.g. `[recipient.name]`); the preview also marks them.
  Whether saving with missing values is allowed is configurable.
* Values come already formatted from the host (amounts, dates); there is no
  schema validation.
* **Hardened configuration**: `api_builtin_enabled=false`,
  `TemplateClassResolver.ALLOWS_NOTHING_RESOLVER`, a data model made only of maps,
  lists and strings, HTML escaping by default.

=== Context

The owner needs loops and blocks, visible missing placeholders, default values
and no validation against a data schema. The syntax is not decisive;
`${...}` is what he had in mind. Thymeleaf would be fine.

=== Decision Drivers

* Loops, conditions and defaults.
* Making missing values visible.
* Security with templates maintained by users.
* Closeness to the desired syntax.

=== Considered Options

==== Option 1: Apache FreeMarker

Syntax `${...}`, defaults built in, easy to harden. Produces arbitrary text, so
HTML escaping must be configured explicitly.

==== Option 2: Thymeleaf

Natural HTML templating, widespread in Spring. Placeholders sit in attributes
(`th:text`) or as `[[${...}]]`; SpEL expressions are harder to harden.

==== Option 3: Mustache or Handlebars

Low on logic and therefore safer. Defaults and the desired behaviour for missing
values have to be built by us; syntax `{{...}}`.

=== Pugh Matrix

`+1` means better support, `0` neutral, `-1` weaker
support and `?` a rating that needs human review or
a prototype. If a column contains a `?`, its sum is `?` as well.

=== Consequences

==== Positive

* The desired expressive power without a template engine of our own.

==== Negative

* The security configuration must be tested and frozen (R-004).

==== Neutral or Follow-Up

* Security tests for known FreeMarker SSTI payloads as part of the test suite.
