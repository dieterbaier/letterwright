== Technischer Kontext

[cols="1,2,2", options="header"]
|===
| Nachbar | Schnittstelle | Richtung
| React-Frontend des Hosts | npm-Paket mit React-Komponenten | Host bettet Komponenten ein
| Spring-Boot-Backend des Hosts | Spring-Boot-Starter, REST unter konfigurierbarem Pfad | In-Process
| Fachdomäne des Hosts | SPIs `PlaceholderDataProvider`, `AuthorizationCheck`, `DeletionPolicy` | Bibliothek ruft Host
| Datenbank des Hosts | JDBC, Liquibase-Changelog | Bibliothek schreibt und liest eigene Tabellen
| Spring Security des Hosts | Authentifizierter Benutzer, Rollen | Bibliothek liest
|===

Voraussetzung beim Host ist Java 21 oder neuer; die Bibliothek wird mit
`--release 21` gebaut (xref:adr-009-build-monorepo-und-versionen[ADR-009]). Ab
welcher Spring-Boot-Version der Starter läuft, weist #32 nach. Alle weiteren
Versionen steuert der Versionskatalog; sie sind keine Architekturentscheidung.

Systemgrenze: Alles innerhalb von *Standardschreiben* liefert die Bibliothek;
Domänendaten, Identitäten, Datenbank und Betrieb gehören dem Host. Dieselbe Grenze
zeigt die xref:building-block-view[Bausteinsicht].
