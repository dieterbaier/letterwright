== Technical Context

[cols="1,2,2", options="header"]
|===
| Neighbor | Interface | Direction
| Host React frontend | npm package with React components | Host embeds components
| Host Spring Boot backend | Spring Boot starter, REST under a configurable path | In-process
| Host business domain | SPIs `PlaceholderDataProvider`, `AuthorizationCheck`, `DeletionPolicy` | Library calls host
| Host database | JDBC, Liquibase changelog | Library writes and reads its own tables
| Host Spring Security | Authenticated user, roles | Library reads
|===

The host must run Java 21 or newer. The library is built with
`--release 21` (xref:adr-009-build-monorepo-und-versionen[ADR-009]). #32
establishes the minimum Spring Boot version the starter runs on. The version
catalog controls all other versions; they are not an architecture decision.

System boundary: the library delivers everything inside *letterwright*.
Domain data, identities, database and operations belong to the host. The
xref:building-block-view[building block view] shows the same boundary.
