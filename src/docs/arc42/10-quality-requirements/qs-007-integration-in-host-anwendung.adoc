== QS-007: Integration in eine Host-Anwendung

=== Status

Vorgeschlagen (proposed).

Das Antwortmaß ist ein prüfbarer Zielwert. Unsichere Werte gelten als Annahmen,
bis sie bestätigt sind.

=== Szenario

[cols="1,3", options="header"]
|===
| Element | Beschreibung
| Source | Entwickler einer Host-Anwendung
| Stimulus | Bindet Starter und npm-Paket ein, implementiert den Platzhalterdaten-Port und bindet den Liquibase-Changelog ein.
| Environment | Bestehende Anwendung mit eigener Datenbank, eigener Security und ggf. JPA.
| Artifact | Spring-Boot-Starter, SPIs, Liquibase-Changelog, React-Komponenten.
| Response | Vorschau und Speichern funktionieren, ohne dass bestehende Konfiguration des Hosts geändert werden muss.
| Response Measure | Integration in ≤ 1 Arbeitstag anhand der Doku; maximal 3 Interfaces zu implementieren; keine Änderung an JPA- oder Security-Konfiguration außer Rollen-Mapping.
|===

=== Begründung

Das Paket soll in bestehende Anwendungen integriert werden.

=== Annahmen

* Die Beispielanwendung dient als Referenz für die Integration.
