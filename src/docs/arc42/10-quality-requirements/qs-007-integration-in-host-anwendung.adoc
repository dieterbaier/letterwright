== QS-007: Integration into a Host Application

=== Status

Proposed.

The response measure is a reviewable target. Treat uncertain values as
assumptions until confirmed.

=== Scenario

[cols="1,3", options="header"]
|===
| Element | Description
| Source | Developer of a host application
| Stimulus | Adds the starter and the npm package, implements the placeholder data port and includes the Liquibase changelog.
| Environment | Existing application with its own database, its own security and possibly JPA.
| Artifact | Spring Boot starter, SPIs, Liquibase changelog, React components.
| Response | Preview and save work without having to change the host's existing configuration.
| Response Measure | Integration in ≤ 1 working day based on the documentation; at most 3 interfaces to implement; no change to the JPA or security configuration except role mapping.
|===

=== Rationale

The package is meant to be integrated into existing applications.

=== Assumptions

* The sample application serves as the reference for the integration.
