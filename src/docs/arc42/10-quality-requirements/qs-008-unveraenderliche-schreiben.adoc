== QS-008: Immutability of Saved Letters

=== Status

Proposed.

The response measure is a reviewable target. Treat uncertain values as
assumptions until confirmed.

=== Scenario

[cols="1,3", options="header"]
|===
| Element | Description
| Source | Template manager and host application
| Stimulus | Change the letterhead, letter template or domain data after a letter was saved.
| Environment | Normal operation.
| Artifact | Saved letter and document store.
| Response | The download returns the original PDF; the metadata name the template versions used.
| Response Measure | The SHA-256 of the download equals the checksum computed at save time in 100 % of cases.
|===

=== Rationale

The owner has confirmed that saved PDFs stay unchanged.

=== Assumptions

* The document store does not change stored bytes.
