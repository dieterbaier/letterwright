== QS-009: Access Protection on Download

=== Status

Proposed.

The response measure is a reviewable target. Treat uncertain values as
assumptions until confirmed.

=== Scenario

[cols="1,3", options="header"]
|===
| Element | Description
| Source | Logged-in user without permission for a specific letter
| Stimulus | (a) Calls download or delete with the ID of someone else's letter. (b) Calls the list while the database holds visible letters and letters of others.
| Environment | Normal operation; the attacker knows or guesses IDs.
| Artifact | REST endpoints and use cases.
| Response | (a) The request is rejected; the response does not distinguish between not present and not permitted. (b) The list contains only letters that the host releases; filtering happens before pagination and counting.
| Response Measure | (a) 100 % of the access attempts by ID return 404 without document content, file name, recipient or subject. (b) In a test case with visible letters and letters of others, 0 letters of others appear as an entry or as metadata; the total count, page count and pagination cursor correspond only to the visible letters.
|===

=== Rationale

Letters contain personal data.

=== Assumptions

* IDs are not sequential (UUID).
