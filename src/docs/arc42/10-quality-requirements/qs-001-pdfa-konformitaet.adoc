== QS-001: PDF/A-Konformität gespeicherter Schreiben

=== Status

Vorgeschlagen (proposed).

Das Antwortmaß ist ein prüfbarer Zielwert. Unsichere Werte gelten als Annahmen,
bis sie bestätigt sind.

=== Szenario

[cols="1,3", options="header"]
|===
| Element | Beschreibung
| Source | Benutzer (Sachbearbeiter)
| Stimulus | Speichert ein Standardschreiben, das mit aktuellen Daten befüllt ist.
| Environment | Normalbetrieb; alle Referenzvorlagen im CI.
| Artifact | Rendering-Adapter und Konformitätsprüfung.
| Response | Das System erzeugt ein PDF und persistiert es nur, wenn es konform ist.
| Response Measure | 100 % der gespeicherten PDFs und aller Referenz-PDFs im CI: 0 veraPDF-Fehler für PDF/A-2b.
|===

=== Begründung

Archivierbarkeit ist eine Kernanforderung aus Issue #1.

=== Annahmen

* veraPDF kann im CI und optional zur Laufzeit ausgeführt werden.
