== QS-001: PDF/A Conformance of Saved Letters

=== Status

Proposed.

The response measure is a reviewable target. Treat uncertain values as
assumptions until confirmed.

=== Scenario

[cols="1,3", options="header"]
|===
| Element | Description
| Source | User (clerk)
| Stimulus | Saves a letter template that is filled with current data.
| Environment | Normal operation, also with templates newly maintained by business users; in addition, all reference templates in CI.
| Artifact | Rendering adapter and required conformance checker (`ConformanceChecker`).
| Response | The system creates a PDF and persists it only if the runtime check confirms it as conformant. If it is not conformant or the check cannot be run, nothing is persisted and the user is informed (fail-closed). Without a configured checker, the application context does not start.
| Response Measure | 100 % of the persisted PDFs have a passed runtime check against PDF/A-2b (0 persisted PDFs without a check result); all reference PDFs in CI: 0 veraPDF errors; tests show: not conformant, check failed and checker missing lead to no persisted letter.
|===

=== Rationale

Archivability is a core requirement from issue #1.

=== Assumptions

* veraPDF runs in CI and at runtime. The starter uses veraPDF as the `ConformanceChecker` by default; a configured checker is required for every persistence (ADR-005).
