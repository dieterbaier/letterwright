== QS-011: Testabdeckung als Build-Gate

=== Status

Vorgeschlagen (proposed).

Das Antwortmaß ist ein prüfbarer Zielwert. Unsichere Werte gelten als Annahmen,
bis sie bestätigt sind.

=== Szenario

[cols="1,3", options="header"]
|===
| Element | Beschreibung
| Source | Entwickler oder KI-Agent
| Stimulus | Öffnet einen Pull Request mit ungetestetem Code.
| Environment | CI in GitHub Actions.
| Artifact | Build-Pipeline.
| Response | Die Pipeline schlägt fehl und nennt Modul und unterschrittene Metrik.
| Response Measure | Gate greift in 100 % der Fälle bei < 80 % Zeilen- oder Zweigabdeckung in einem Backend-Modul oder Frontend-Paket.
|===

=== Begründung

Issue #1 fordert 80 % Abdeckung, der Owner verlangt Prüfung für Zeilen und Zweige in Backend und Frontend.
