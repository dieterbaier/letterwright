== QS-011: Test Coverage as a Build Gate

=== Status

Accepted on 2026-11-18 by the owner during the review of
epic #4 (issue #37).

The response measure is a reviewable target. Treat uncertain values as
assumptions until confirmed.

=== Scenario

[cols="1,3", options="header"]
|===
| Element | Description
| Source | Developer or AI agent
| Stimulus | Opens a pull request with untested code.
| Environment | CI in GitHub Actions.
| Artifact | Build pipeline.
| Response | The pipeline fails and names the module and the metric that fell short.
| Response Measure | The gate takes effect in 100 % of cases at < 80 % line or branch coverage in a backend module or frontend package.
|===

=== Rationale

Issue #1 requires 80 % coverage; the owner requires a check for lines and branches in the backend and frontend.

=== Assumptions

* Generated code is excluded.
