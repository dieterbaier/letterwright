[[qs-010-fehlende-platzhalter-sichtbar]]
== QS-010: Fehlende Platzhalterwerte sind sichtbar

=== Status

Vorgeschlagen (proposed).

Das Antwortmaß ist ein prüfbarer Zielwert. Unsichere Werte gelten als Annahmen,
bis sie bestätigt sind.

=== Szenario

[cols="1,3", options="header"]
|===
| Element | Beschreibung
| Source | Benutzer
| Stimulus | Öffnet die Vorschau eines Standardschreibens, für das der Host einen Wert nicht liefert.
| Environment | Normalbetrieb.
| Artifact | Zusammenführung von Vorlage und Daten, Vorschau.
| Response | Der Platzhalter erscheint sichtbar markiert und ist für Screenreader als fehlender Wert erkennbar; ein Defaultwert wird verwendet, wenn definiert.
| Response Measure | 100 % der fehlenden Werte ohne Default sind in Tests sichtbar markiert; 0 Abbrüche der Vorschau wegen fehlender Werte.
|===

=== Begründung

Vom Owner gefordertes Verhalten.

=== Annahmen

* Die Markierung erscheint nicht im gespeicherten PDF, wenn Speichern mit fehlenden Werten gesperrt ist.
