== QS-013: Style Fidelity to the Central DOCX Specification

=== Status

Proposed.

The response measure is a reviewable target. Treat uncertain values as
assumptions until confirmed.

=== Scenario

[cols="1,3", options="header"]
|===
| Element | Description
| Source | Central department that issues the DOCX specification
| Stimulus | Compares a PDF generated by the library with the PDF export of the DOCX specification.
| Environment | The letterhead was created once by the template manager in the editor according to the specification.
| Artifact | Style specifications of the letterhead, rendering, generated PDF.
| Response | Font, font sizes, line spacing, paragraph spacing and the positions of logo, sender, address field and footer match the specification.
| Response Measure | For the sample DOCX files delivered later: the same font (or a free substitute font confirmed by the central department) and font size per style, embedded in the PDF; deviation of positions and spacing ≤ 1 mm; acceptance by the central department in the prototype.
|===

=== Rationale

The owner requires that the styles of the central specification are right in the result, even if they are maintained in the editor instead of in Word.

=== Assumptions

* *Style fidelity is taken as given* (owner, 2026-11-21). There is no access to
  the central department for the acceptance. The project assumes that the result
  fits: the prototype deviates at most 0.1 mm from the Word PDF. Whether the tool
  is fit for purpose will be shown by the first real customer use, and that is
  only possible with a production-ready state.
* The host provides the licensed fonts of the specification and holds the
  license for embedding and web font use.
* Technical fallback and business acceptance are separate. If a font is missing,
  the library uses a free substitute font from
  xref:adr-017-bereitstellung-der-schriften[ADR-017], and the spike can already
  measure it. For the substitute case, however, QS-013 is only met once the
  central department has confirmed the substitute font and the tolerances of the
  response measure are kept.
* The specification uses named Word styles and not mainly direct formatting.

=== Open Questions

* Who accepts the style fidelity from the business side? For now nobody; see the
  first assumption.
* Does the central department accept the free substitute fonts from ADR-017 if
  the host does not provide the original fonts? Open above all for Arial
  Narrow.
