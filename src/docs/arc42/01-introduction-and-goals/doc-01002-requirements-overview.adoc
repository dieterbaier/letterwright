== Requirements Overview

Source: issue #1 and the owner's answers in the issue.

.Users (clerks)
* Preview a letter generated from a letter template using current data.
* Save letters; the result is a download link.
* List of the saved letters.
* Download or print saved letters.
* Delete saved letters (the host application decides the rules).
* Multi-page letters with automatic page breaks and page numbers (MVP).
* The host application decides roles and visibility.

.Template managers (business users)
* Define letterheads: type private or business (DIN 5008 form A or B,
  default B), style rules from the central DOCX specification, header with slogan and logo, sender, recipient address, subject,
  information blocks on the first page, footer, page numbers.
* Define letter templates, with placeholders, repeat and
  condition blocks, and default values.
* Assign a letterhead to a letter template.

.Not in the MVP (later, possibly)
* Multiple languages for templates and UI.
* Enclosures.
* Multi-tenancy (explicitly not required).
