== R-004: Template Injection via Maintained Templates

=== Status

Proposed.

This risk was identified with AI assistance. It names a topic for review and
does not decide risk acceptance.

=== Risk Statement

Because templates are maintained by users and evaluated with a powerful template language, a manipulated expression may call Java classes or methods, leading to code execution and data leakage in the host application.

=== Assessment

[cols="1,3", options="header"]
|===
| Field | Value
| Likelihood | Low.
| Impact | High.
| Priority | High.
| Timeframe | Near-term.
| Confidence | High.
|===

Known attack pattern (SSTI); well controllable with a restrictive configuration.

=== Mitigation Options

* Hardened FreeMarker configuration according to ADR-008.
* Data model made only of maps, lists and strings.
* Automated tests with known SSTI payloads.
* Maintenance right only for authorized template managers.

=== Decision or Acceptance

The risk remains under analysis until the accountable owner confirms the
assessment and mitigation.
