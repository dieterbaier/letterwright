== R-003: Maintenance State of the HTML-to-PDF Library

=== Status

Proposed.

This risk was identified with AI assistance. It names a topic for review and
does not decide risk acceptance.

=== Risk Statement

Because openhtmltopdf is a community project with few maintainers, bugs may remain unfixed or updates may not come, which endangers the conformance and the security of the PDF generation.

=== Assessment

[cols="1,3", options="header"]
|===
| Field | Value
| Likelihood | Medium.
| Impact | Medium.
| Priority | Medium.
| Timeframe | Medium-term.
| Confidence | Low.
|===

Maintenance state checked on 2026-11-21: `io.github.openhtmltopdf` released
version 1.1.114 on 2026-11-16, and the repository is not archived. This lowers
the likelihood, but changes the rating only after the review by the
owner.

=== Mitigation Options

* Encapsulate the renderer behind the port `Renderer`.
* Check the maintenance state and license (LGPL) before accepting ADR-004.
* An alternative (Apache FOP or Chromium) as a documented fallback. Customers
  mostly accept Apache FOP with XSLT; if a customer rejects openhtmltopdf, it is
  the fallback according to ADR-004, option 3. The owner does not choose it for
  now because it is too heavyweight for him (2026-11-21).
* The PDFBox post-processing of the footer (ADR-004) depends on how
  openhtmltopdf writes the content stream. Its verification on every generation
  and a test for each update of openhtmltopdf catch changes; the alternative
  path is a regular, tagged block in the letter layout.

=== Decision or Acceptance

The risk remains under analysis until the accountable owner confirms the
assessment and mitigation.
