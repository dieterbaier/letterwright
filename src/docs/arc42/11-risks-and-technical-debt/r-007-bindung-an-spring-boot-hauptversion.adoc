== R-007: Binding to the Spring Boot Major Version

=== Status

Accepted on 2026-11-18.

This risk was identified with AI assistance. The owner reviewed and accepted it
during the review of epic #4 (issue #37), as well as its outgoing
relation.

=== Risk Statement

Because a Spring Boot starter is bound to the major version of Spring Boot and Spring Framework, hosts on older versions cannot include the library, which restricts the target group.

=== Assessment

[cols="1,3", options="header"]
|===
| Field | Value
| Likelihood | Medium.
| Impact | Medium.
| Priority | Medium.
| Timeframe | Medium-term.
| Confidence | Medium.
|===

Depends on which hosts actually integrate.

=== Mitigation Options

* Keep the domain and application free of Spring (ADR-002), so that a second starter line is cheap.
* Name the supported versions clearly in the documentation.

=== Decision or Acceptance

The owner has confirmed the assessment and mitigation and accepted the risk on
2026-11-18 (issue #37).
