[[r-007-bindung-an-spring-boot-hauptversion]]
== R-007: Bindung an die Spring-Boot-Hauptversion

=== Status

Angenommen (accepted) am 2026-11-18.

Dieses Risiko ist KI-gestützt identifiziert. Der Owner hat es bei der Prüfung
von Epic #4 geprüft und akzeptiert (Issue #37), ebenso seine ausgehende
Relation.

=== Risk Statement

Weil ein Spring-Boot-Starter an die Hauptversion von Spring Boot und Spring Framework gebunden ist, können Hosts auf älteren Versionen die Bibliothek nicht einbinden, was die Zielgruppe einschränkt.

=== Assessment

[cols="1,3", options="header"]
|===
| Field | Value
| Likelihood | Medium.
| Impact | Medium.
| Priority | Medium.
| Timeframe | Medium-term.
| Confidence | Medium.
|===

Hängt davon ab, welche Hosts tatsächlich integrieren.

=== Mitigation Options

* Domäne und Anwendung frei von Spring halten (ADR-002), damit eine zweite Starter-Linie günstig ist.
* Unterstützte Versionen in der Doku klar nennen.

=== Decision or Acceptance

Der Owner hat Bewertung und Mitigation bestätigt und das Risiko am 2026-11-18
akzeptiert (Issue #37).
