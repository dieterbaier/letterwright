== R-008: Access Hurdle with GitHub Packages

=== Status

Proposed.

This risk was identified with AI assistance. It names a topic for review and
does not decide risk acceptance.

=== Risk Statement

Because GitHub Packages requires authentication even for public Maven and npm packages, consumers must configure tokens, which makes the integration harder and slows down external use.

=== Assessment

[cols="1,3", options="header"]
|===
| Field | Value
| Likelihood | High.
| Impact | Low.
| Priority | Low.
| Timeframe | Medium-term.
| Confidence | High.
|===

Known behavior of GitHub Packages; low impact as long as consumers are internal.

=== Mitigation Options

* Describe the configuration in the integration documentation.
* For external use, evaluate Maven Central and npmjs.org.

=== Decision or Acceptance

The risk remains under analysis until the accountable owner confirms the
assessment and mitigation.
