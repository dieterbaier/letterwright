== R-008: Zugangshürde bei GitHub Packages

=== Status

Vorgeschlagen (proposed).

Dieses Risiko ist KI-gestützt identifiziert. Es benennt ein Thema zur Prüfung
und entscheidet nicht über die Risikoakzeptanz.

=== Risk Statement

Weil GitHub Packages auch für öffentliche Maven- und npm-Pakete eine Authentifizierung verlangt, müssen Konsumenten Tokens konfigurieren, was die Integration erschwert und externe Nutzung bremst.

=== Assessment

[cols="1,3", options="header"]
|===
| Field | Value
| Likelihood | High.
| Impact | Low.
| Priority | Low.
| Timeframe | Medium-term.
| Confidence | High.
|===

Bekanntes Verhalten von GitHub Packages; Auswirkung gering, solange Konsumenten intern sind.

=== Mitigation Options

* Konfiguration in der Integrationsdoku beschreiben.
* Bei externer Nutzung Maven Central und npmjs.org bewerten.

=== Decision or Acceptance

Das Risiko bleibt in Analyse, bis der verantwortliche Owner Bewertung und
Mitigation bestätigt.
