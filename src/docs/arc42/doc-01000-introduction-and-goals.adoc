[[introduction-and-goals]]
= Einführung und Ziele

Standardschreiben ist eine einbettbare Bibliothek für Spring-Boot-/React-Anwendungen.
Sie zeigt Benutzern Standardschreiben auf einem definierten Briefpapier, befüllt mit
aktuellen Domänendaten, als barrierefreie Vorschau an und speichert sie auf Wunsch
als barrierefreies PDF/A-Dokument zum Download.
