[[deployment-view]]
= Verteilungssicht

Standardschreiben hat keine eigene Laufzeitumgebung. Das Backend-Artefakt läuft in
der JVM der Host-Anwendung, das Frontend-Paket wird in das Frontend-Bundle des Hosts
eingebaut. Tabellen liegen in der Datenbank des Hosts.

[cols="1,3", options="header"]
|===
| Artefakt | Verteilung
| Maven-Artefakte (Starter und Module) | GitHub Packages (xref:adr-012-distribution-ueber-github-packages[ADR-012])
| npm-Paket | GitHub Packages
| Liquibase-Changelog | Im Starter enthalten, vom Host eingebunden
| Schriften | Im Rendering-Adapter und im npm-Paket eingebettet, frei lizenziert
|===
