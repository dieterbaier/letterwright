[[deployment-view]]
= Deployment View

letterwright has no runtime environment of its own. The backend artifact runs
in the JVM of the host application. The frontend package is built into the
host's frontend bundle. Tables live in the host's database.

[cols="1,3", options="header"]
|===
| Artifact | Distribution
| Maven artifacts (starter and modules) | GitHub Packages (xref:adr-012-distribution-ueber-github-packages[ADR-012])
| npm package | GitHub Packages
| Liquibase changelog | Contained in the starter, included by the host
| Fonts | The host provides the licensed fonts of the DOCX specification in a configurable folder, in every environment. The library ships only free substitute fonts and a free default font; system fonts are not used. Preview and PDF use the same file (xref:adr-017-bereitstellung-der-schriften[ADR-017]).
|===
